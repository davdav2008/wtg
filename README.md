# Property Booking REST API

REST API на Laravel для імпорту пропозицій житла, пошуку найдешевших пропозицій та бронювання.

## Технології
- PHP 8.2+
- Laravel 11/12
- MySQL 8+
- Redis/Database for Queues

## Встановлення та запуск

1. Клонувати репозиторій.
2. Встановити залежності:
   ```bash
   composer install
   ```
3. Скопіювати `.env.example` у `.env` та налаштувати підключення до БД:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
4. Запустити міграції та сідери (створює постачальників `supplier-a` та `supplier-b`):
   ```bash
   php artisan migrate --seed
   ```
5. Запустити чергу для обробки імпортів:
   ```bash
   php artisan queue:work
   ```
6. (Опціонально) Запустити вбудований сервер:
   ```bash
   php artisan serve
   ```

## Тестування
Запуск тестів (Feature tests для Import, Search, Reservation):
```bash
php artisan test
```

## Деталі реалізації

### Ідемпотентність імпорту
Ідемпотентність забезпечується на кількох рівнях:
1. **База даних**: Таблиця `imports` має унікальний індекс на комбінацію `(supplier_id, external_import_id)`.
2. **Контролер**: Перед створенням нового запису імпорту перевіряється наявність існуючого за цим ключем. Якщо імпорт вже існує, повертається його поточний статус без створення дубліката або повторного запуску Job.
3. **Обробка пропозицій**: У `ProcessImportJob` використовується метод `updateOrCreate` (через `firstOrNew` та `fill`) для кожної пропозиції на основі `supplier_id` та `external_id`, що дозволяє оновлювати існуючі офери замість створення дублікатів.

### Захист від Double Booking
Для запобігання бронювання останньої одиниці двома одночасними запитами використано атомарну операцію на рівні бази даних:
- У методі `CreateReservationAction` виконується запит:
  ```sql
  UPDATE offers SET available_units = available_units - 1 
  WHERE id = ? AND available_units > 0
  ```
- Це гарантує, що `available_units` не стане від'ємним і лише один процес зможе успішно зменшити лічильник, якщо залишилася 1 одиниця.
- Додатково вся логіка створення запису бронювання обгорнута в базу транзакцію.

### Пошук найдешевшої пропозиції
Пошук виконується одним SQL-запитом з використанням віконної функції `ROW_NUMBER() OVER (PARTITION BY property_id ORDER BY price ASC)`, що дозволяє ефективно отримати лише одну (найдешевшу) актуальну пропозицію для кожного об'єкта житла безпосередньо в MySQL.
